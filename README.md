# Image Text Campaign Skill

A reusable Skill package for creating branded graphic and text content. The archive includes the Skill instructions, two reusable Prompts, single-company and Top 3 HTML templates, scripts, and a production playbook.

## Download

Download [image-text-campaign.zip](./image-text-campaign.zip) and extract it. The complete package structure and setup instructions are included in the archive's `README.md`.

## 中文说明

这是一个用于制作品牌图文内容的 Skill 包，包含 Skill、两份 Prompt、单品牌与 Top 3 图文模板、脚本和制作说明。下载上方压缩包并解压，按包内 README 安装和使用。


## 常见问题

**成品图片没有背景图，只有文字和卡片？**

背景图不在包内分发——每期作品的主题场景不同，背景需要按当期疑问句现生成。渲染器会在背景缺失时报错中止并列出缺失文件。补救方式见包内 README 的"常见问题"节，或 `references/production-playbook.md` 第 2 步。
